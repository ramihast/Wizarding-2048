Wizarding 2048

Wizarding 2048 is a magical-school take on the classic 2048 puzzle. Slide enchanted objects around the board, merge matching items, and unlock increasingly powerful wizarding artifacts. Reach 2048, then keep playing to discover what comes next.

## Play online

**Live game:** [Play Wizarding 2048](https://ramihast.github.io/Wizarding-2048/)

Replace the URL above with your GitHub Pages address after publishing the game.

## How to play

- Move the tiles with the arrow keys or WASD on desktop.
- Swipe on the board or use the on-screen direction buttons on touch devices.
- Matching artifacts merge into the next artifact in the magical progression.
- Keep merging to earn points and reach new milestones. The game continues beyond 2048.
- Use **Undo** to reverse your last move and **New Game** to start over.

## Features

- Responsive 4×4 puzzle board for desktop and mobile
- Wizarding artifacts, atmospheric visuals, and magical merge effects
- Keyboard, swipe, and touch-button controls
- Score tracking, best score, undo, and saved progress
- Milestone celebrations with endless progression
- Optional sound and reduced-animation settings
- No installation required

## Run locally

Download or clone this repository and open `index.html` in a modern web browser.
